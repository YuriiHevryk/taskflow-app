# TaskFlow RAG — Порівняння BEFORE / AFTER

## Методика порівняння

Результати BEFORE взято з `baseline-results.md`: для всіх десяти запитів зафіксовано успішний текстовий пошук із повідомленням «нотаток не знайдено» та оцінку 0/2. Результати AFTER взято з контрольного послідовного експерименту, описаного в `after-results.md`: усі 10 MCP-викликів успішні, без технічних помилок і повторів. Оцінки AFTER поставлено за змістом реально повернутих фрагментів, а не за малою векторною відстанню.

## Висновок

У цьому контрольному запуску семантичний пошук повернув релевантний контекст для всіх десяти запитань і дав 15/20 проти 0/20 у задокументованому BEFORE. Водночас п'ять відповідей були частковими: фрагменти не містили всіх потрібних деталей. Повернення фрагментів саме по собі не означає повноту: оцінки ґрунтуються на їхньому змісті. Для Q10 не знайдено підтвердження затвердження SQLite Backup API; це не є доказом відсутності такого рішення в усій базі знань. Для Q08 джерело називає JSON варіантом, який **запропоновано**, тож оцінка підтверджує достатність пояснення мотивів, але не статус затвердження цього рішення.

Час виконання не вимірювався.
